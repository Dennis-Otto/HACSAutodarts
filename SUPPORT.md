# Support

Use GitHub issues for reproducible bugs, compatibility reports, and focused feature requests. Include the integration version, Home Assistant version, Board Manager version, setup type (local or cloud), relevant sanitized logs or diagnostics, expected behavior, and reproduction steps.

This community project does not provide guaranteed response times or private operational support. It is not affiliated with Autodarts. Never post access tokens, board API keys, private network addresses, or personal data.

Suspected vulnerabilities must not be reported in a public issue. Follow `SECURITY.md` instead.
